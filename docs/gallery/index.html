Previewing does not change your desktop. Opening, closing and optional resize work on stock Niri. Choose the setup you already use:

Plain Niri or WaybariNiR / iRiSDankMaterialShellNoctalia

For a simple first try, get NiriFX and run niri-fx. Choose the same preset name in the terminal guide, review the files, then apply. Run it again and choose Undo to restore your previous settings. A shell picker can manage selection instead. Quickshell is optional.

For a customized look, download its JSON and use Copy local command to open it in local Studio. Follow the download-to-desktop guide.
